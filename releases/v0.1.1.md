# DalPDF 0.1.1

- PDF 원본 텍스트·이미지 편집, 분할·병합, 연속 읽기
- 내장 로컬 번역, 전체 문서 번역, 번역 PDF 저장
- 긴 문장 분할, 한도 확대, 남은 페이지 이어서 번역
- 용어 교정, 핵심 안내, 문서 질문, 쉬운 설명, 버전 비교
- Windows CPU/Vulkan GPU 선택 및 Mac Metal 가속
- 새 버전 확인 후 사용자 동의로 설치하는 서명 검증 자동 업데이트

기존 0.1.0 사용자는 이번 버전을 한 번 직접 설치해 주세요. 이후 업데이트는 앱에서 안내합니다.

macOS Apple Silicon / Windows x64. Windows GPU 실기기 성능은 미검증입니다. Apple 공증 및 Windows 코드 서명은 적용하지 않았으며, 자동 업데이트 파일에는 별도 암호학적 서명을 적용합니다. Windows 번역 엔진에는 Microsoft Visual C++ v14 x64 런타임이 필요하며 GPU 모드는 Vulkan 지원 드라이버가 필요합니다.
