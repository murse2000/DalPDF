# DalPDF 0.1.2

- 상단 제목·도구 영역을 68px로 줄여 문서 표시 공간 확대
- Ctrl + 마우스 휠로 25~300% 확대·축소, 마우스 위치 유지
- 확대 중 기존 페이지를 유지하고 새 이미지가 준비되면 교체하여 깜빡임 개선
- 번역 시 표의 셀·열과 제목·본문을 분리하여 원본 배치 유지
- 원본 글자 크기를 기준으로 영역 안에 번역문 맞춤. 직접 지정한 크기도 영역을 넘으면 축소
- 위첨자 주변의 잘못 추출된 줄바꿈으로 번역문이 작아지는 문제 수정
- 화면과 저장 PDF에 동일한 번역 배치 적용

기존 번역에는 현재 페이지 번역을 다시 실행해야 새 구간 분리가 적용됩니다. 업데이트 전에 편집·번역 결과를 저장해 주세요. 앱에서 업데이트 설치를 선택하면 서명 검증 후 설치·재시작합니다.

macOS Apple Silicon / Windows x64. 내장 로컬 번역 모델 포함. Apple 공증과 Windows Authenticode 서명은 미적용이며, 업데이트 파일은 별도 서명으로 검증합니다. Windows GPU 실기기 성능은 미검증입니다. 복잡한 병합 셀과 모든 PDF 서식의 완전한 복원은 보장하지 않습니다.
