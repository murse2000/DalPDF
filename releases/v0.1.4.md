# DalPDF 0.1.4

- Windows에서 인쇄 준비 중 `failed to persist temporary file: 액세스가 거부되었습니다. (os error 5)`가 발생하던 문제 수정
- 인쇄용 임시 파일의 핸들을 닫은 후 PDF를 저장하도록 변경. 원문·번역문 인쇄 모두 적용
- 인쇄 종료·취소·준비 실패 시 임시 파일 자동 정리 유지
- 내용 편집 패널을 열 때 화면 크기 변경과 개체 조회가 겹치면 텍스트를 클릭해도 선택되지 않던 문제 수정

AI 모델은 바뀌지 않았습니다. 0.1.3에서 업데이트할 때 기존 모델의 무결성이 확인되면 모델을 제외한 경량 업데이트를 받습니다. 사용자가 업데이트 설치에 동의한 뒤 다운로드합니다.

macOS Apple Silicon / Windows x64. Apple 공증과 Windows Authenticode 서명은 미적용이며 업데이트 파일은 별도 서명으로 검증합니다.
