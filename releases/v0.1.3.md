# DalPDF 0.1.3

- 추가한 이미지와 기존 이미지를 마우스로 드래그하여 이동하고 한 번에 실행 취소
- 선택한 텍스트에 형광펜 표시, 접고 펼칠 수 있는 포스트잇 메모 추가
- 메모 내용 수정과 드래그 위치 이동, 표준 PDF 주석 저장
- 문서 도우미의 길이 한도 오류와 근거 검색 개선
- 핵심 안내 결과를 페이지 근거와 함께 PDF·Markdown으로 내보내기
- 시스템 인쇄 대화상자와 Ctrl+P / Cmd+P 지원, 원문·번역 보기의 현재 내용을 인쇄
- 번역된 불릿 목록의 글자 겹침 수정
- 회전된 페이지가 섞인 문서의 너비 맞춤과 중앙 정렬 수정
- 왼쪽 메뉴를 줄이고 페이지 미리보기 추가, 페이지 이동을 하단 중앙으로 배치
- 시작 시 기본 PDF 앱 설정 여부 확인 및 사용자 동의 절차 추가
- Windows 업데이트에서 실행 파일이 종료될 때까지 기다린 후 교체하도록 수정
- 동일한 AI 모델을 재사용하는 경량 업데이트 지원

0.1.2 이하에서 이번 버전으로 업데이트할 때는 모델을 포함한 전체 설치 파일을 받습니다. 이후에는 모델이 같고 기존 모델의 무결성이 확인되면 모델을 제외한 경량 업데이트를 사용합니다. 새 버전 알림에서 사용자가 설치에 동의한 뒤 다운로드합니다.

기존 번역에는 해당 페이지 번역을 다시 실행해야 새 배치가 적용됩니다. 업데이트 전에 편집·번역 결과를 저장해 주세요. Windows 기본 앱 설정은 시스템 설정에서 사용자가 최종 선택합니다.

macOS Apple Silicon / Windows x64. 로컬 AI 모델 포함. Apple 공증과 Windows Authenticode 서명은 미적용이며 업데이트 파일은 별도 서명으로 검증합니다.
