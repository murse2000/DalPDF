## 엔진 성능 측정

실제 구현의 파일 열기 및 페이지 크기 조회, 렌더링·PNG 인코딩·Base64 변환 경로를 측정했습니다. 테스트 직후 파일 캐시가 따뜻한 상태이며, 실제 사용자의 문서와 압축 방식은 다를 수 있습니다.

- 입력: 독립적인 1024×768 픽셀 이미지 120장과 페이지별 텍스트
- 파일 크기: 283,447,325바이트
- 파일 열기 및 전체 페이지 크기 조회: 약 0.81ms
- 첫 페이지 1500px 렌더링·PNG·Base64: 약 18.33ms
- 표본 7페이지 처리: 약 17.09~17.67ms
- 원시 측정값: `tests/performance.json`

이는 엔진 측정값입니다. UI 첫 표시 시간, WebView 프로세스 전체 메모리, GPU 프레임률 또는 모든 문서에서 무중단 스크롤을 보장하는 수치는 아닙니다.

## 2026-09-13 Windows GPU 가속 옵션

- 번역 패널의 AI 가속에 Windows CPU/GPU 선택 추가. 설정은 앱 설정 폴더의 `gpu-acceleration.json`에 저장하며 번역과 문서 도우미가 같은 엔진을 사용함. 기본값 CPU, Mac Metal 실행 인자는 유지.
- GPU 선택 시 고정 버전 엔진의 `--list-devices`로 Vulkan 장치를 확인하고 여유 메모리가 가장 큰 장치를 선택. 검사 제한 시간 15초. 드라이버 미지원/장치 없음은 오류로 안내하고 설정 저장을 진행하지 않음.
- GPU 실행에는 장치 ID, `--gpu-layers all --fit off --split-mode none` 지정. 전체 모델을 담을 메모리가 부족하면 CPU 변경 안내. CPU는 별도 엔진에 `--device none --gpu-layers 0`을 지정. 활성 장치 표시는 모델의 health 응답 이후에만 제공.
- `npm run check` 통과. Node 11개, Rust 7개 통과. 추가 테스트는 로그 중 실제 Vulkan 장치만 추출, 여러 GPU 선택, GPU 없음, 플랫폼별 엔진 경로와 실행 인자를 검증.
- 실제 Mac 내장 모델의 짧은 문장 번역 테스트 별도 통과. 최신 앱에서 AI 가속 항목과 Mac Metal 표시 확인. 전체 PDF 번역 검증은 재개하지 않음.
- 공식 b10809 Windows Vulkan ZIP을 SHA256 `97e50b3ef0cdd2cb4d5afd446a9006b3496bee6c0d0ba7083d32f36075771870`으로 검증. 엔진·Vulkan DLL·라이선스 목록과 개별 해시는 `windows-gpu-packaging.json`에 기록.
- Vulkan DLL의 import에서 `vulkan-1.dll`, MSVC v14 런타임 의존성을 확인. 해당 드라이버 및 시스템 런타임은 동봉하지 않으며 README에 명시.
- 최종 Windows NSIS 설치 파일에 CPU/Vulkan 엔진과 MIT/OpenMP 라이선스 포함 확인. Mac 앱 서명·DMG 검증 및 두 설치 파일의 SHA256 검증 통과.

Windows GPU 실기기 실행, GPU 설정 저장/복원의 실제 Windows 동작 및 CPU 대비 속도 향상은 미검증입니다. Mac 테스트나 교차 빌드가 이를 입증하지 않습니다.
