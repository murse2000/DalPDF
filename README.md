# DalPDF

DalZip의 곰·초승달 브랜드와 남색 유리 질감을 적용한 Windows/macOS PDF 뷰어·편집기입니다. Tauri 2 + TypeScript UI와 Rust/PDFium 엔진으로 구성했습니다. 문서는 서버로 업로드하지 않습니다.

## 구현한 기능

- 파일 선택, 드래그 앤드 드롭, OS의 PDF 파일 연결로 열기
- 상단 버튼으로 왼쪽 사이드바 숨기기·펼치기. 전환할 때 읽던 위치 유지
- 연속 스크롤, 확대·축소, 너비 맞춤, 페이지 이동, 문서 텍스트 검색
- 화면 주변 페이지만 렌더링하고, 이미지 캐시는 최대 8개 및 약 64MiB의 문자열 용량으로 제한
- PDF 페이지 범위 추출: `1-3, 5`처럼 입력해 새 PDF로 저장
- 현재 문서 뒤에 여러 PDF의 페이지 합치기
- 원래 들어 있던 텍스트 개체의 내용 수정. 흰 사각형으로 가리는 방식이 아닙니다.
- 원본 글꼴에 입력 문자가 없으면 변경을 취소합니다. TTF 글꼴을 직접 선택해 해당 텍스트 개체를 교체할 수도 있습니다.
- 기존 이미지 교체, 새 이미지 추가, 위치·크기 변경, 90도 회전, 픽셀 범위 자르기, 개체 삭제
- 디스크에 보관하는 20단계 실행 취소와 다시 실행
- 다른 이름으로 저장, 저장 결과 재열기 검증, 같은 디렉터리에서 완성 파일 교체

## 현재 편집 범위와 제한

- 텍스트는 PDF 개체 단위로 수정합니다. Word처럼 문단 전체의 줄바꿈과 재배치를 자동으로 처리하지 않습니다.
- 최상위 텍스트·이미지 개체를 편집합니다. Form XObject 내부의 중첩 개체는 현재 읽기 전용으로 표시합니다.
- 스캔 이미지 안의 글자는 텍스트 개체가 아니므로 직접 텍스트 수정 대상이 아닙니다. OCR은 구현하지 않았습니다.
- TTF 대체 시 텍스트의 변환, 채움색, 렌더링 모드와 페이지 개체 순서를 유지합니다. 클리핑된 텍스트의 글꼴 교체는 지원하지 않습니다.
- 암호 입력 UI, 디지털 서명 유지, 양식 편집은 현재 제공하지 않습니다.
- 저장은 전체 PDF를 다시 기록합니다. 큰 문서의 편집 이력 생성 및 저장에는 디스크 공간과 시간이 필요합니다.
- UI는 Liquid Glass에서 영감을 받은 공통 웹 UI입니다. Apple의 네이티브 Liquid Glass API를 사용하는 SwiftUI 앱은 아닙니다.

## 실행 파일

- `artifacts/DalPDF.app`: macOS Apple Silicon 실행 앱
- `artifacts/DalPDF-0.1.2-arm64.dmg`: macOS 설치 이미지
- `artifacts/DalPDF-0.1.2-x64-setup.exe`: Windows x64 설치 파일
- `artifacts/SHA256SUMS`: 설치 파일 해시

Windows 버전은 macOS에서 교차 빌드했습니다. 실제 Windows 기기에서 설치·실행·편집 검증은 아직 하지 못했습니다. 배포용 Apple 공증 및 Windows 코드 서명은 적용하지 않았습니다.

## 개발 및 검증

Node.js 24 이상, Rust, 해당 OS의 Tauri 빌드 도구가 필요합니다.

```sh
npm ci
node scripts/fetch-pdfium.mjs
npm run app:dev
npm test
npm run check
npm run app:build -- --bundles app
```

Windows에서 빌드:

```sh
node scripts/fetch-pdfium.mjs --windows
npm run app:build -- --bundles nsis --config src-tauri/tauri.windows.conf.json
```

macOS에서 Windows 교차 빌드 시 `cargo-xwin`, Windows x64 Rust 타깃, Homebrew LLVM/LLD/NSIS가 필요합니다.

```sh
node scripts/fetch-pdfium.mjs --windows
python3 scripts/build-windows-cross.py
```

대용량 엔진 측정은 별도로 실행합니다. 테스트용 약 283MB PDF를 생성하므로 디스크 공간이 필요합니다.

```sh
cargo test --release --manifest-path src-tauri/Cargo.toml large_document_measurement -- --ignored --nocapture --test-threads=1
```

측정 결과 및 실제 앱 검증 내용은 `tests/VERIFICATION.md`에 기록했습니다.

## PDF 엔진 및 라이선스

PDFium chromium/8044를 사용하고 `pdfium-render` 0.9.4를 고정했습니다. PDFium 바이너리와 그 배포본의 라이선스·제3자 고지를 앱 리소스에 함께 포함합니다.

- PDFium: https://pdfium.googlesource.com/pdfium/+/refs/heads/main/LICENSE
- PDFium API: https://pdfium.googlesource.com/pdfium/+/main/public/fpdf_edit.h
- Rust 바인딩: https://github.com/ajrcarey/pdfium-render
- 고정 바이너리 배포본: https://github.com/bblanchon/pdfium-binaries/releases/tag/chromium/8044

달베어 웹사이트는 이번 환경에서 DNS 조회가 실패하여 직접 확인하지 못했습니다. 디자인은 로컬 DalZip 아이콘과 스타일을 기준으로 적용했습니다.

## 내장 오프라인 번역

상단 **번역**을 누르면 오른쪽 번역 패널이 열립니다. PDF 위에서 드래그하거나 선택 단위를 **문장 / 문단**으로 바꾸고 글자를 누른 뒤 **선택 내용 번역**을 누르세요. **현재 페이지 번역**은 화면의 현재 페이지 전체 텍스트를 번역합니다. 기본 언어는 한국어이며 영어·일본어·중국어도 선택할 수 있습니다. 번역이 끝나면 PDF의 원문 위치에 번역문이 표시됩니다. 상단 **원문 보기 / 번역문 보기**로 즉시 전환할 수 있고 오른쪽 패널에서 전체 번역문을 복사할 수 있습니다. 번역하지 않은 페이지는 원문을 표시합니다. 이 전환은 보기 기능이며 원본 PDF와 저장 내용은 바뀌지 않습니다.

설치 파일에 llama.cpp b10809와 Qwen3-4B-Instruct-2507 Q3_K_S 모델(1,886,997,600바이트)을 함께 포함합니다. 별도 번역 프로그램, API 키, 계정, 최초 모델 다운로드가 필요하지 않습니다. 번역할 때 DalPDF 내부 리소스의 엔진을 자식 프로세스로 실행합니다. 통신은 임의 포트의 127.0.0.1에만 바인딩하고 실행마다 생성한 인증 키를 사용합니다. HTTP 프록시와 리다이렉트를 사용하지 않으며 엔진도 `--offline`으로 실행합니다. 외부 번역 API에 연결하거나 문서를 전송하지 않습니다. 번역 취소·앱 종료 시 엔진을 종료합니다. PDF 렌더링과 번역은 별도 작업기로 동작합니다.

모델 때문에 설치 용량이 약 2GB 증가하고 번역 중 추가 메모리가 필요합니다. macOS 13.3 이상 Apple Silicon은 Metal, Windows x64는 기본으로 동봉 CPU 엔진을 사용합니다. Windows는 번역 패널의 **AI 가속 → 번역 처리 장치 → GPU · 빠른 번역**에서 내장 Vulkan 엔진을 선택할 수 있습니다. Vulkan 호환 NVIDIA·AMD·Intel GPU와 최신 그래픽 드라이버, 모델과 문맥을 담을 충분한 그래픽 메모리가 필요합니다. 별도 번역 엔진이나 모델을 설치하지 않습니다. 여러 GPU가 있으면 현재 여유 메모리가 가장 큰 장치를 사용하며, 준비가 끝나면 장치 이름을 표시합니다. 전체 모델 레이어를 GPU에 배치하므로 메모리가 부족하면 CPU로 변경해야 합니다. 설정은 재실행 후에도 유지되고 문서 도우미에도 적용됩니다. AI 작업 중에는 변경할 수 없습니다. 번역 속도는 기기에 따라 다르며 Windows GPU 실기기 성능은 아직 측정하지 않았습니다. 문단 경계는 빈 줄과 줄 간격으로 추정하며 다단 편집·복잡한 PDF의 추출 순서는 시각적 읽기 순서와 다를 수 있습니다. 한 페이지 안에서 선택할 수 있습니다. 스캔 이미지 OCR은 제공하지 않습니다. 자동 번역에는 오역이 있을 수 있으므로 원문 대조가 필요합니다.

빌드 전에 `python3 scripts/fetch-translation.py`(Mac) 또는 `python scripts/fetch-translation.py windows`를 실행하세요. 빌드용 다운로드만 외부 저장소에 접속하며 고정 리비전과 SHA256으로 엔진·모델을 검증합니다. macOS에서 Windows 교차 빌드할 때는 두 플랫폼 리소스를 각각 준비해야 합니다. 모델 및 엔진의 라이선스는 설치 리소스와 `licenses/TRANSLATION-NOTICES.txt`에 포함합니다.

Windows 내장 엔진은 Microsoft Visual C++ v14 x64 런타임을 사용합니다. `MSVCP140.dll` 또는 `VCRUNTIME140.dll`이 없는 PC는 [Microsoft 공식 재배포 패키지](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist?view=msvc-170)가 필요합니다. Vulkan 드라이버와 이 시스템 런타임은 DalPDF 설치 파일에 포함하지 않습니다.

번역문 보기에서는 원본 페이지 한 장을 메모리에서 복제하고 텍스트의 표시만 숨긴 배경 위에 번역문을 배치합니다. 선택 번역은 선택한 글자 위치만 해당 배경으로 복원합니다. 번역문은 원래 문단 영역에 들어가도록 글자 크기를 조절하므로 긴 번역은 작아질 수 있으며, 패널에서는 전체 크기의 텍스트를 확인할 수 있습니다. 원본의 모든 글꼴·회전·복잡한 다단 레이아웃을 그대로 재현하는 조판 기능은 아닙니다. 번역 데이터는 현재 열어 둔 문서에서만 유지되며 문서 내용 편집이나 새 문서 열기 시 초기화합니다.

번역 패널의 **번역문 글꼴·크기**에서 내장 Noto Sans KR(고딕체)·Noto Serif KR(명조체) 글꼴을 선택할 수 있습니다. 크기는 **문단에 자동 맞춤** 또는 **직접 지정(6~72pt)**으로 설정합니다. 모든 번역 페이지와 결과 패널에 즉시 적용되며, 직접 지정한 크기는 확대/축소 비율을 따라갑니다. 문단 영역을 넘는 번역문은 해당 영역 안에서 스크롤하여 읽을 수 있습니다. Mac과 Windows에서 같은 내장 글꼴을 사용하며 원본 PDF의 글꼴이나 저장 내용은 바뀌지 않습니다. 설정은 현재 앱 실행 중 유지됩니다.

## 문서 전체 번역 및 번역 PDF 저장

- **문서 전체 번역**: 모든 페이지를 순서대로 번역하며 페이지/구간 진행률을 표시합니다. 취소해도 완료된 페이지의 결과는 유지됩니다. 텍스트가 없는 페이지는 원문을 유지합니다.
- **번역 PDF 저장**: 현재 완료된 번역을 새 파일로 저장합니다. 번역하지 않은 페이지는 원본 페이지를 그대로 복사합니다. 원본 파일 이름으로 덮어쓰기는 허용하지 않습니다.
- 번역된 페이지는 배경을 폭 1,800px(최대 높이 4,000px), JPEG 품질 95의 이미지로 보존하고 번역문은 글꼴을 포함한 실제 PDF 텍스트 개체로 저장합니다. 번역문은 선택·검색 및 내용 편집이 가능합니다. 번역 페이지의 기존 그림·도형은 개별 벡터 개체 대신 한 장의 배경 이미지가 됩니다. 선택 번역 페이지의 번역되지 않은 글자도 배경에 포함됩니다.
- 화면과 저장에 동일한 내장 글꼴, 크기, 줄바꿈 계산을 사용합니다. 직접 지정한 글자 크기가 문단 영역을 넘으면 잘라 저장하지 않고 자동 맞춤 또는 작은 크기를 선택하도록 안내합니다.
- 번역 PDF는 새 문서로 생성하며 원본의 문서 수준 책갈피·서명·양식 구조 보존은 지원하지 않습니다. 원본은 보존됩니다.

## 문서 도우미

상단 **문서 도우미**에서 다음 기능을 사용합니다. 번역과 같은 내장 모델을 공유하며, 한 번에 한 AI 작업을 실행합니다. 문서를 읽는 화면은 유지되고 진행 중 취소할 수 있습니다.

- **핵심 안내**: 문서 전체를 구간별로 읽어 핵심 카드와 근거 페이지를 만듭니다. 필요할 때 시작하므로 PDF를 여는 동안 모델 준비를 기다리지 않습니다.
- **문서 질문**: 질문의 관련 용어를 생성하고 원문 구간을 검색한 뒤, 관련 부분만 모델에 전달합니다. 근거가 없는 응답은 `문서에서 확인되지 않음`으로 표시합니다. 인용문은 모델이 다시 쓰지 않고 선택한 출처 ID의 실제 원문에서 가져옵니다. 출처 버튼을 누르면 페이지로 이동하고 해당 구간을 강조합니다.
- **쉽게 설명**: 번역 패널에서 원문의 문장·문단을 선택한 뒤 **선택 내용 쉽게 설명**을 누릅니다. 선택한 구간의 원문을 함께 보여줍니다.
- **문서 비교**: 현재 PDF를 이전 버전으로, 선택한 PDF를 새 버전으로 비교합니다. 페이지 삽입·삭제를 포함한 텍스트 차이를 별도 작업기에서 계산하고, 필요한 변경 구간에만 AI 설명을 요청합니다. 이미지·서식·스캔 글자는 비교하지 않습니다.
- **용어집**: 원문 용어와 올바른 번역을 기기에 저장합니다. 기존 번역을 고칠 때는 기존 번역 용어도 입력하고 변경 전후를 확인한 뒤 선택한 문단에 적용합니다. 교정 결과는 번역 PDF 저장에 반영됩니다. 용어는 번역 언어별로 최대 200개 저장하며 앱을 다시 실행해도 유지됩니다.

AI의 출처 선택과 설명은 틀릴 수 있습니다. 출처 ID 및 실제 인용문 일치 검사는 의미의 정확성까지 보장하지 않습니다. 문서 질문은 관련 구간 검색을 이용하므로 문서 전체의 모든 사실을 항상 찾아내는 것은 아닙니다. 원문 편집·새 문서 열기 시 문서 도우미 결과와 검색용 텍스트를 초기화합니다. 용어집은 유지됩니다.

## 긴 문서 번역 및 이어서 처리

모델 문맥은 16,384토큰, 일반 번역 구간의 출력 상한은 8,192토큰입니다. 짧은 구간은 반복 출력을 줄이기 위해 1,024토큰 상한을 사용합니다. 원문은 최대 1,200문자 구간으로 나누고, 출력 한도에 도달하면 해당 구간을 더 작게 나눠 다시 처리합니다. 잘린 응답을 정상 번역으로 저장하지 않습니다.

단일 영문 회로 표기·숫자·핀 번호·표준 약어는 그대로 보존합니다. 이 항목에 사용자가 지정한 용어가 있으면 해당 번역을 적용합니다. 페이지 하나가 실패해도 문서의 다음 페이지를 계속 처리하며, 실패한 페이지와 이유를 표시합니다. **남은 페이지 이어서 번역**은 같은 언어로 완료한 페이지를 건너뛰고 미완료 페이지를 처리합니다. 완료된 번역은 현재 앱 세션에서 유지되므로 앱 종료 전에 번역 PDF로 저장하세요.

## 릴리즈와 자동 업데이트

소스: https://github.com/murse2000/DalPDF

앱 시작 5초 후, 이후 6시간마다 새 릴리즈를 확인합니다. 하단 **업데이트 확인**으로 직접 확인할 수도 있습니다. 새 버전이 있으면 **업데이트 설치 / 나중에**를 묻습니다. 설치 버튼을 누르기 전에는 파일을 내려받지 않습니다. 저장하지 않은 편집·번역 결과 및 진행 중인 작업이 있으면 설치를 막습니다. 다운로드 서명을 검증한 뒤 설치하고 앱을 다시 시작합니다. 업데이트 확인에는 GitHub 접속이 필요하지만 PDF 내용은 전송하지 않습니다.

0.1.0에는 업데이트 기능이 없으므로 0.1.1을 한 번 직접 설치해야 합니다. 서명 개인키는 Git에 포함하지 않으며 로컬 보안 폴더와 GitHub Actions의 `TAURI_SIGNING_PRIVATE_KEY` Secret으로 관리합니다. 키를 잃으면 기존 설치본용 업데이트를 서명할 수 없으므로 별도로 백업해야 합니다.

배포 절차: 앱·패키지·Cargo 버전을 함께 올리고 `releases/v버전.md`를 작성한 뒤 `v버전` 태그를 푸시합니다. GitHub Actions가 Mac/Windows를 검증·패키징하고 서명된 설치 파일과 `latest.json`을 모두 업로드한 뒤 릴리즈를 공개합니다. 이미 공개된 릴리즈는 덮어쓰지 않습니다.
